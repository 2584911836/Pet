# 素材与来源

## 游戏内素材

| 内容 | 来源与实现 | 当前状态 |
|---|---|---|
| 108 种灵兽 | `game_data.gd`、`pixel_art.gd`；九类手写像素基础轮廓和十二类结构变化，名称、生态、技能、属性、区域独立记录 | 已可遇见/捕捉/查看；还需美术与独立性审查 |
| 主角洛汐 | 自有像素图案与绘制代码，含地图角色和档案头像 | 已使用 |
| 地图与航图 | 程序绘制植被、水面、营地、灯塔、道路、石碑、岛屿航线 | 已使用；环境细节仍可扩充 |
| 配乐 | `audio.gd` 中合成器与原创旋律序列，`bake_audio.gd` 生成六个 WAV | 已使用；需要真人听感评估 |
| 音效 | 由合成器根据事件生成短音序列 | 已使用 |
| 标题插画 | 使用本会话的图像生成工具生成，原始任务描述为原创潮汐群岛、守灯人及三只原创同伴；文件 `assets/art/title_archipelago.png` | AI 生成的标题插画，不是实际地图截图 |
| 中文字体 | Noto Sans CJK Regular，来自系统字体包，SIL Open Font License 1.1 | 字体及完整许可一并提供 |

标题插画的生成日期为 2026-10-18（北京时间），原始生成文件保留在开发工作区，项目内为未修改副本。没有引用其他游戏的角色或商标素材。生成工具产出和程序绘制并不代替正式发行前的知识产权审查；不得宣称经过律师或平台认证。
