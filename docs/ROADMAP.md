# 《潮汐灵约》制作与发行路线

## 产品方向

面向喜欢短篇探索、队伍搭配和可爱生物的单机玩家，做一款可一次买断的精致小体量收集 RPG。采用原创世界观、轮廓、美术、文本、UI 和音效；不使用宝可梦的角色、精灵球、名称、音效或素材，也不以相关商标包装商品。

暂定核心卖点：潮汐会改变岛屿路径、灵兽生态和战斗环境；同一种灵兽在不同潮相可发挥不同定位。**已实现手动潮相切换**，影响浅滩通行、遭遇种类与技能增益。当前验证探索—遭遇—战斗/捕捉—成长—三岛灯塔—结局闭环。下一版本应优先加入潮相，而非堆积更多同质怪物。

## 当前已实现

三座小岛、九种灵兽、三角克制、六只队伍、捕捉、升级、防御恢复、营地补给、失败恢复、遗迹守卫、自动/手动存档。图形由代码绘制，属于原型素材；已加入合成音乐/音效、章节文本、基础手柄映射、标题和暂停菜单、音量/全屏设置、图鉴与储备编队；尚无剧情演出、多存档槽、可重绑键位、英语文本或 Steam SDK 集成。没有商业收入或市场验证证据。

## 建议制作关卡

1. **玩法验证**：加入两种潮相、可预见的遭遇点、各灵兽两种差异化技能；找 5–10 名目标玩家实际试玩，记录能否独立理解捕捉与克制、是否愿意继续。解决重复防御/刷级等平衡问题。
2. **可公开演示版**：约 20–30 分钟，包含教学、一个完整剧情任务、6–8 种差异化灵兽、一个有机制的首领。补上原创美术、音乐音效、暂停设置、音量、键位与手柄、中文字体和英文文本。建立素材来源与授权台账。
3. **商店与市场验证**：名称检索后制作真实截图、短预告、胶囊图与准确描述。创建 Steam 商店页，参加适合的试玩活动，观察试玩完成率、反馈和愿望单增长，再决定扩充预算。不得用当前规划冒充已上线内容。
4. **商业首发候选**：目标 3–5 小时主线、约 18–24 种灵兽、3 个生态区域、明确结局。数量是范围假设，需要按人力与试玩反馈收缩。完成 Windows 实机测试、存档兼容、键鼠/手柄、不同分辨率、离线启动、卸载重装与性能检查。

这些是阶段范围，不是已承诺的交付日期；预算、团队规模和可投入时间尚未确定。

## 盈利假设

优先买断制，无抽卡、无强制联网、无内购。可先测试人民币 28–48 元的价格接受度，再按内容品质、同类产品和 Steam 区域定价工具调整，不能据此预测销量。

用实际合同费率、税费、退款率与折扣估算每份净收入；回本销量 = 总成本 ÷ 每份净收入。总成本应包含人工、美术、音频、翻译、测试、商店费用和营销。不要把流水当利润。先用试玩反馈与愿望单验证需求，再增加内容投资。

## Steam 上架所需的外部工作

由发行主体开通 Steamworks、完成身份/税务/收款资料并承担平台费用；以 Steamworks 当前官方要求为准，提交前重新核查审核和等待期。不能由本仓库或无窗口验证代替。

准备 Windows 独立构建（Linux 可选）、商店文案、真实截图、预告、胶囊图、内容问卷、素材授权和隐私说明（若采集数据）。原型目前不采集遥测。成就、云存档和 Steam Deck 适配可后续加入，基础离线单机玩法不需要先接入 SDK。

发行前必须完成真人试玩、全流程回归、字体及全部资源授权审查、商标/名称检查、定价与宣传验证。当前已验证官方导出模板校验和并生成 Windows/Linux 独立包；没有 Steamworks 账户接入、Windows 实机验收、签名可执行包或已提交商店页；尚未发布，也无法保证盈利。
