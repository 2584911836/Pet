# 《星野伙伴》游戏设计文档

版本：v0.10.0。状态：当前已实现玩法说明。实现基准：v0.10.0 源码。整理日期：2026 年 10 月 19 日，北京时间。

本文把当前实现与未来计划分开描述；不是商业发行验收或盈利预测。物种详细数据见 [108 种伙伴目录](PET_CATALOG.csv)，剧情原文见 [剧情设计](STORY.md)。

## 1. 产品定位

| 项目 | 当前设计 |
|---|---|
| 游戏名称 | 星野伙伴 / Starwild |
| 类型 | 2D 单机伙伴收集、养成与回合制冒险 RPG |
| 引擎 | Godot 4.6.3 |
| 体验主轴 | 收集图鉴、建立队伍、成长为训练师、寻找并救出父母 |
| 视觉 | 像素风场景与角色小人，搭配精细伙伴美术、人物立绘和图形化 UI |
| 已实现内容规模 | 108 种伙伴、十二属性、三个地区九个区域、五场主线挑战 |
| 交付形式 | 可导入运行的 Godot 项目源码 |
| 计划发行 | 面向 PC / Steam 的付费单机游戏；售价、时长承诺与发行日期未确定 |

目标玩家是喜欢收集、组队和轻量策略的单机 RPG 玩家。当前没有联机、内购或遥测。游戏不依赖网络运行。

设计原则：伙伴有用途；克制信息可预测；主线目标清楚；失败可恢复；长期收集不能阻止情感主线结局。

## 2. 世界观与故事

洛汐的父母是生态研究员。他们发现有人违规转移伙伴、伪造运输记录，因为拒绝配合而被困在研究站。父母留下的图鉴与研究手记成为调查起点。

阿岚帮助洛汐核对栖息地和运输编号。地区训练师资格既检验队伍能力，也让调查办公室逐步开放资料和调查许可。洛汐先救出父母，再回到赛场完成自己的冠军梦想。

当前世界没有灯塔、潮汐、涨退潮道路或环境切换。本区地形通道永久开放，跨区道路由资格解锁，物种在所属区域全天可遇见；没有水、火环境伤害加成。

### 主要人物

| 人物 | 身份与作用 |
|---|---|
| 洛汐 | 玩家角色，带着父母的研究手记出发，初始伙伴为苔芽兽 |
| 父母 | 生态研究员、失联调查对象；救援结束后确认平安 |
| 阿岚 | 调查引导者，解释联赛、父母与温和捕捉，提供地区生态委托 |
| 茵禾 | 生态观测员，核对本区域四种伙伴记录，提供调查线索 |
| 乔渡 | 驿道巡查员，通过不同地区的问题教授安全、证据与备战 |
| 春蕾、唐砾、凌朔 | 三地导师，分别负责地区资格考核 |
| 许澈 | 对手训练师、调查线索提供者，也是冠军赛对手 |
| 研究站封锁员 | 救援篇的战斗对手 |

冠军不是救援的交换条件。父母获救与冠军完成分别保存，输掉后续比赛不会撤销家人已获救的结果。

## 3. 核心循环

**查看目标 → 探索区域 → 遭遇伙伴 → 战斗或捕捉 → 获得经验与资格积分 → 调整队伍 → 挑战训练师 → 推进调查与剧情。**

长期循环是寻找未记录物种、完善属性覆盖、完成可选调查和收集全部 108 种伙伴。

当前初始即有一只伙伴，无开局三选一。探索采用格子移动；进入草丛格时有 23% 概率触发遭遇。每区固定有 12 种可遇见伙伴，每地区共 36 种。选取遭遇时存在优先从未记录物种中抽取的倾向，但不是必定遇见新物种。

## 4. 主线结构与关卡

| 阶段 | 条件与地点 | 对手 | 完成结果 |
|---|---|---|---|
| 青芽资格 | 本地区 3 资格积分；青芽镇东北赛场 | 春蕾：3 级泡鳍灵 | 第一徽章、全队一级指导、解锁赤岩 |
| 赤岩资格 | 本地区 3 资格积分；赤岩镇东北赛场 | 唐砾：5 级焰盔蟹 | 第二徽章、全队一级指导、解锁星原 |
| 星原资格 | 本地区 3 资格积分；联赛中心东北赛场 | 凌朔：7 级星潮龙 | 第三徽章、全队一级指导、取得救援许可 |
| 父母救援 | 三枚徽章；研究站外围东北入口 | 8 级琥珀蝎、风炉蜥 | 击败全部阵容后，父母获救状态保存 |
| 冠军赛 | 父母已获救；联赛中心东北赛场 | 9 级浮岛蝾、星潮龙、钩月羚 | 击败全部阵容后获得冠军，进入自由探索 |

资格积分由野外获胜或捕捉成功获得，每次 1 分，每地区最多记录 3 分。已有资格不能通过正常赛场入口重复领取指导奖励。

救援战与冠军赛是连续阵容战斗。对方换宠不会补满己方能量，也不会重新发放药草。击败第一只对手不提前发放整场胜利奖励或推进剧情。

**108 全图鉴不是资格、救援或冠军赛门槛。** 可选 NPC 委托也不阻塞主线。

### 地图结构

| 地区 | 城镇 / 主赛场 | 调查区 | 驿道 / 特殊区域 |
|---|---|---|---|
| 青芽 | 青芽镇 | 曙光林 | 溪谷驿道 |
| 赤岩 | 赤岩镇 | 琥珀矿径 | 货运栈道 |
| 星原 | 联赛中心 | 星冠林 | 研究站外围 |

当前每张区域地图为 18×11 格参考网格，九区分别使用环境调色与场景主题：青芽广场、林池古树、河湾栈桥、赤岩集镇、矿池轨道、货运堆场、星纹广场、银叶夜池、研究站温室。新增石板路、木栈道、民居与各区地标；水域和建筑具有实际碰撞。主通路仍共享参考网格，尚不是大型开放世界。

营地位于西侧，提供免费恢复与胶囊补给。城镇东北是导师赛场，野外东北为巡查站，研究站外围东北是救援入口。世界地图显示九个可点击区域节点及其道路。每个地区的城镇、调查区、驿道互相连通；溪谷驿道连接赤岩镇，货运栈道连接联赛中心。

三个资格挑战全部完成前，只能沿相邻且已解锁的节点通行。青芽资格开放赤岩地区，赤岩资格开放星原地区，道路可双向返回。地图使用实线显示开放道路、虚线显示资格锁定道路、金框标记当前位置。全部三个资格挑战完成后，永久解锁全图传送，可点击任意其他节点直接抵达。

可直接走向场景边界的金色箭头跨入相邻区域，无需菜单操作；从目标区域对应的道路入口落地，可原路返回。红色箭头代表资格锁定。主线跨区追踪通过地区图搜索下一跳，再引导角色走到该出口。

使用地图菜单切换时从营地附近开始，步行切换从对应入口开始；两者均不自动恢复生命，治疗仍需在营地休息。探索侧栏也提供相邻区域的通行入口，日志中的跨区主线入口打开节点地图，不绕过道路限制。传送解锁由已保存的三枚资格徽章计算，兼容旧存档。

## 5. 伙伴收集与养成

### 数据与个体

已实现 108 个物种的名字、外形、生态、栖息地区、基础生命、攻击、属性、被动和专属技能。每只伙伴固定拥有 1–2 种属性，不会生成第三种属性。

个体保存物种编号、等级、当前 / 最大生命与经验。当前没有性格、个体值、努力值、性别、繁殖、进化或稀有异色系统。

### 队伍与背包

- 随行最多 6 只，后备最多 200 只。
- 队伍未满时捕捉加入队伍；满员后加入后备。后备达到上限时需先整理。
- 背包显示图片、等级、生命、属性和技能，支持查看个体与选择出战。
- 队伍与后备的存取、交换需在营地旁进行。
- 不能存入最后一名可战斗伙伴，倒下的伙伴不能设为出战。
- 图鉴记录保留，放归后备个体不删除其物种发现记录；放归需要确认。

### 成长

每场完整战斗获胜或捕捉成功，当前出战伙伴获得 1 经验；Lv.1–5 每级需 3 点经验，此后每 5 级增加 1 点需求，最高每级 20 点，上限 99 级。可累计经验并支持连续升级，到达上限后不继续累积经验。升级最大生命增加 6、基础战力增加 2，并恢复生命。探索界面显示生命 / 经验条，背包详情显示个体等级、下级经验需求及成长收益。

首次通过每地资格时，随行全队额外获得一级指导，未满 99 级者最大生命相应增加 6；训练师挑战完成后恢复队伍。当前没有全队共享常规经验或技能学习树。

## 6. 十二属性系统

属性克制根据**招式属性**与目标全部属性计算，不直接以攻击者物种属性代替招式属性。

| 属性 | 克制 | 被克制 |
|---|---|---|
| 金 | 木、冰、土、龙 | 火、雷 |
| 木 | 水、土 | 金、火、冰、虫 |
| 水 | 火、虫 | 木、土、雷、冰 |
| 火 | 金、木、冰、虫 | 水、土 |
| 土 | 水、火、雷 | 金、木、风 |
| 风 | 土、虫 | 冰、雷 |
| 雷 | 水、金、风 | 土 |
| 光 | 暗 | 暗 |
| 暗 | 光 | 光 |
| 冰 | 木、水、风 | 金、火 |
| 龙 | 龙 | 金、龙 |
| 虫 | 木 | 火、风、水 |

单项克制 ×1.5，其他 ×1.0；双属性分别计算并相乘，最高 ×2.0。光暗互克、龙克自身。没有自动反向抵抗、免疫或本系伤害加成；固定持续伤害不重复乘属性倍率。

这张表已实现，但克制覆盖与弱点数量不同，不代表商业平衡已经完成。

## 7. 对战技能与回合规则

当前是玩家选择行动后对方回应的回合制，没有速度排序。普通战斗为双方各一只在场；训练师可按固定阵容依次派出后续伙伴。

### 每宠三招

| 类型 | 能量 | 伤害系数 | 定位 |
|---|---:|---:|---|
| 基础招式 | 0，使用后恢复 1 | 1.0 | 稳定攻击与能量回复，被动可提高回复 |
| 补盲招式 | 消耗 1 | 1.15 | 提供副属性或生态相关覆盖属性 |
| 专属技能 | 消耗 2 | 1.2×物种技能系数 | 物种独立技能名，触发专属效果 |

能量上限 3，进入一场新战斗时补满；己方换宠沿用队伍能量。当前三招固定配置，没有学习、替换或遗忘技能的操作。

主要伤害由攻击、等级、招式系数、属性克制、被动及少量随机浮动构成，再处理标记、回响、破甲、防御和护盾。双方共用属性和技能定义，敌方另有独立能量预算。

### 已实现的 11 类专属效果

| 效果 | 功能 |
|---|---|
| 汲取 | 命中恢复自身生命 |
| 灼伤 | 持续两次侵蚀扣血，不叠加 |
| 缓蚀 | 较低单次伤害、持续三次，不叠加 |
| 护盾 | 吸收后续直接伤害，刷新不累加 |
| 润泽 | 连续两次恢复生命 |
| 破甲 | 接下来两次直接受击增加伤害 |
| 回响 | 下一次直接攻击获得额外伤害 |
| 返息 | 专属技返还 1 能量，并恢复生命 |
| 绝境爆发 | 自身半血及以下额外伤害，否则获得护盾 |
| 追击 | 目标半血及以下增加伤害 |
| 标记 | 目标下一次受到直接攻击时增加伤害 |

不同物种采用不同数值、被动和组合，不是 108 套完全不同的规则。

### 其他行动

- 防御：恢复 1 能量，降低下一次直接攻击伤害；部分被动附带恢复。
- 药草：每场 3 份，通常回复 24 生命，相关被动提高到 30；连续阵容中不重置。
- 安抚：消耗 1 能量，削减约四分之一目标最大生命，最低保留 1 生命。
- 换宠：选择可战斗伙伴，对方行动一次；取消选择不消耗回合，不重置资源。
- 捕捉：消耗胶囊；失败后对方可以行动，成功结束本次野外遭遇。
- 撤离：可离开战斗，未赢得挑战则不推进主线。

敌方在资源足够时每三回合尝试专属技能，其他回合可能选择克制更好的补盲技；训练师每三回合有额外蓄力增强。不存在逐只角色独立的复杂战术 AI。

## 8. 捕捉、补给与失败恢复

训练师的伙伴不可捕捉。野外捕捉概率取决于剩余生命、已发现补给箱和已完成阿岚委托：

`成功率 = min(95%, 20% + 70% × 已损失生命比例 + 补给箱数 × 0.5% + 阿岚委托数 × 2%)`

当前没有状态异常捕捉加成、不同胶囊品质或按键判定小游戏。成功率在战斗按钮显示。

营地免费恢复全队与后备，并把胶囊至少补到 8；低于 8 才补足，不扣除已有更多胶囊。各地区城镇有一次性调查补给箱，可获得胶囊与生命恢复。

全队倒下会被送回营地并恢复，不删除伙伴、图鉴或已完成章节。游戏没有永久死亡、背包掉落或金钱惩罚。当前也没有货币、商店、装备制造与付费道具经济。

## 9. 任务与 NPC 交互

主线日志根据积分、徽章、救援和冠军状态动态显示目标。可追踪主线、营地或本区 NPC；地图路线只提示合法路线，不自动移动，也不会绕过遭遇。已解锁章节可回顾，不重复发奖。

| 委托 | 条件 | 奖励与限制 |
|---|---|---|
| 阿岚地区记录 | 登记本地区至少六种伙伴 | 6 胶囊、全队恢复、永久 +2 个百分点捕捉率；每地区一次 |
| 茵禾区域观察 | 登记她所在林区四种伙伴 | 3 胶囊；每地区一次 |
| 乔渡巡查问题 | 正确回答地区问题 | 3 胶囊；每地区一次，答错无惩罚，可重试 |

阿岚有父母调查、联赛意义、温和捕捉三个分支。乔渡在青芽询问安全接近伙伴，在赤岩询问证据核对，在星原询问研究站备战。

当前没有好感度、恋爱、多结局分歧或自由输入对话。

WASD / 方向键移动，E 营地休息，R 交谈，J 日志，M 本区地图，Esc 菜单 / 返回。界面支持鼠标和键盘焦点；存在部分手柄输入支持，但未完成真实手柄验收与按键重映射。

参考画布为 1152×720，保持纵横比缩放。动态效果包括移动帧、跟随伙伴、待机浮动、受击晃动与数字、捕捉反馈；可减少动态效果。当前不是每只伙伴都拥有独立攻击动画。

使用六首原创合成 WAV 配乐和合成音效，主要人物有立绘；没有完整语音演出。伙伴、人物、标题等采用 AI 辅助美术，来源及校验记录见 [素材文档](ASSETS.md)。

## 11. 存档与技术边界

自动保存队伍、后备、图鉴、地点、积分与徽章、补给箱、NPC 委托、对话标记、追踪目标、父母获救和冠军状态。配置单独保存音量、显示与减少动态设置。

存档采用临时文件写入、替换与备份恢复。旧版物种 ID、等级和收集记录保留；旧三灯塔进度解释为三地资格，旧环境字段忽略，不自动赠送新结局。

当前是单个主存档加备份，没有多存档槽与 Steam 云存档。战斗中退出返回最近存档，不恢复半场战斗。未接入 Steamworks 成就、排行榜或在线服务。

## 12. 验证与未完成事项

v0.9.0 独立源码导入后 2697 项检查通过；20 种子模拟共 299 场战斗，均完成五阶段主线，结束时收集 8–10 种伙伴。另有真实按键 / GUI 流程完成 108 图鉴、三地资格、救援与冠军赛，150 场遭遇、零全队倒下。

自动化覆盖功能与流程，不证明好玩、设备兼容或商业品质。详细边界见 [测试记录](TESTING.md)。

后续优先级：

1. 5–10 名新玩家首玩测试，打磨前 30 分钟引导与剧情理解。
2. 不同收集数量下的养成速度、主线难度、属性与技能平衡。
3. 九区独立布局、更多调查事件与可选路线。
4. 宠物独立动作、视听风格统一、配乐听感与重复疲劳检查。
5. 手柄、重映射、字体尺寸、目标设备性能与异常恢复。
6. 素材权利核查、AI 内容披露、发行构建、Steam 商店页、试玩与定价验证。

进化、繁殖、多人、开放世界、多结局、完整语音和 Steam 集成均不属于当前已实现内容；是否加入需依据试玩结果与制作成本重新决定。
