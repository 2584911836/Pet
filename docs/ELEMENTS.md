# 十二属性与技能（v0.9.0）

宠物属性来自物种设计档案，每只固定为 1–2 种，不会产生第三种属性。招式各自只有一种属性，使用招式属性攻击目标的全部属性。旧存档只保存物种 ID 等个体记录，自动解析新属性，无须删除存档。

| 属性 | 克制 | 被克制 |
|---|---|---|
| 金 | 木、冰、土、龙 | 火、雷 |
| 木 | 水、土 | 金、火、冰、虫 |
| 水 | 火、虫 | 木、土、雷、冰 |
| 火 | 金、木、冰、虫 | 水、土 |
| 土 | 水、火、雷 | 金、木、风 |
| 风 | 土、虫 | 冰、雷 |
| 雷 | 水、金、风 | 土 |
| 光 | 暗 | 暗 |
| 暗 | 光 | 光 |
| 冰 | 木、水、风 | 金、火 |
| 龙 | 龙 | 金、龙 |
| 虫 | 木 | 火、风、水 |

- 克制 ×1.5，其他 ×1.0，没有自动反向抵抗或免疫。
- 双属性分别相乘，最高 ×2；相同属性不会重复叠加。
- 光暗互克、龙克自身，按表直接判定。
- 不存在环境切换或水火环境增伤。
- 灼伤、缓蚀等固定持续伤害不乘属性倍率。
- 金克土、水克虫、土克火、雷克风、金克龙已启用；龙不再克风。

每只宠物装备三招：

1. 基础招式：主属性，伤害系数 1.0，消耗 0，恢复 1 能量；已有被动可提高回复。
2. 补盲招式：双属性通常采用副属性；单属性按生态配置覆盖属性。伤害系数 1.15，消耗 1。
3. 专属技能：物种独立技能名，采用明确指定的本系属性；消耗 2，伤害系数 1.2 × 物种技能系数，触发已有 11 类专属效果。

能量上限为 3。防御恢复 1；切换宠物消耗回合并沿用当前队伍能量。双方使用同一属性倍率和技能定义；敌方拥有独立能量，在有足够资源时每三回合尝试专属技能，其他回合会选择克制更好的补盲招式。训练师每三回合额外蓄力增强。

游戏内：战斗按钮显示招式属性、对当前目标的倍率、消耗；悬停查看详情。背包和图鉴展示完整技能清单，旅程菜单有属性克制手册与关系原因。

本版实现既定关系，不宣称十二属性已平衡；属性分布、双属性收益和招式预算仍需真人试玩。

救援战有 2 名对手伙伴，冠军赛有 3 名，全部击败后才推进剧情。对方换宠不重置己方能量与药草；战斗中的换宠入口会列出随行队伍，取消不花费回合，确认后对手行动一次。
