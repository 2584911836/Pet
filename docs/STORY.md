# 星野伙伴 · 主线与 NPC 设计

## 主线结构

洛汐的父母是生态研究员，因为阻止违规转移伙伴而被困在研究站。阿岚协助核对运输编号；图鉴提供栖息地证据，训练师资格提供调查许可。冠军赛属于洛汐的个人梦想，不能成为父母平安的交换条件。

| 阶段 | 玩家行为 | 解锁与反馈 |
|---|---|---|
| 青芽资格 | 取得 3 资格积分，在青芽镇东北赛场挑战导师 | 第一徽章、全队一级指导、赤岩通行 |
| 赤岩资格 | 调查新区域与属性组合，完成第二导师挑战 | 第二徽章、全队一级指导、研究站线索 |
| 星原资格 | 完成第三导师挑战 | 第三徽章、全队一级指导、救援许可；不是主线结局 |
| 研究站救援 | 前往研究站外围东北入口，连续击败封锁员两名伙伴 | 父母获救单独保存；研究站由调查员接管 |
| 冠军赛 | 返回联赛中心东北赛场，连续击败许澈三名伙伴 | 冠军状态单独保存，进入自由探索与图鉴收集 |

不要求抓满 108 种伙伴。野外胜利与捕捉均能获得资格积分，NPC 委托不阻止主线。失败后可回营地免费恢复，新的救援和冠军挑战可重试。

## 交互与引导

- J 日志根据真实状态更新下一目标，提供任务地区入口、主线 / 营地 / NPC 追踪与已解锁章节回顾。
- M 本区地图显示合法地形、不可通行边界、当前位置、赛场或研究站、NPC、追踪路线。
- 地图上的路线由当前障碍 BFS 计算，不自动移动玩家，也不绕过遭遇。
- R 优先与附近的区域 NPC 交互，其次是赛场接待或营地阿岚；靠近 NPC 格子会触发交谈并保留玩家位置。
- 地区导师只在城镇赛场考核，野外调查点不会重复举行资格赛。

## NPC

- 阿岚：父母失联、联赛意义、温和捕捉三个分支；根据资格和主线状态给出下一步，提供六种地区图鉴委托。
- 茵禾：每地区林区四种图鉴记录，解释记录与运输编号的关联；独立立绘，一次性胶囊奖励。
- 乔渡：青芽考察伙伴接近方式，赤岩考察记录证据，星原考察研究站准备。答错不扣物品，答对只领奖一次；独立立绘。
- 三地导师与许澈：赛场接待展示对手属性、备战提示；冠军对手有独立的三名伙伴阵容。

## 持久化

旧存档文件名及目录保留。旧三灯塔记录解释为三地资格，不直接赠送救援与冠军完成状态。对话、区域委托与章节回顾不会重复发奖；新增终章状态经过布尔类型和前置条件验证。

## v0.10.0 步行探索

跨区主线追踪先通过区域图寻找下一跳，再将本区路线引向边界出口。金色箭头允许直接步行过图，目标入口与来路对应；红色箭头受地区资格限制。进入研究站或返回冠军赛场均可以沿实际道路完成，不强制使用地图菜单。
