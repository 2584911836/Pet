# v0.5.1 验证记录

环境：Godot 4.6.3，Debian 云环境。图形检查使用 Xvfb 与 Mesa llvmpipe；这是软件渲染验证，不是目标玩家硬件的性能认证。

## 已完成

- `tests/smoke.gd`：33 项系统检查，全部通过。涵盖战斗、奖励、克制、队伍、升级、潮相、岛屿门槛和存档恢复。
- `tests/interface.gd`：29 项 UI 检查，全部通过。真实键盘事件、按钮回调、设置保存、出招期间重复操作保护、新游戏备份、石碑、图鉴分页、区域和档案、满级非致命安抚、NPC 交谈、一次性委托奖励、契约增益与保存。
- `tests/catalog.gd`：679 项检查，全部通过。108 个唯一名字、108 张实际图集宠物美术的不同缩略图、108 个不同 alpha 轮廓、每个区域 12 种、每个潮相的遭遇池非空、全部 108 种可遇见、完整收藏存档读回。独立轮廓证明不是单纯换色，不证明艺术品质已达到商业标准。
- `tests/campaign.gd`：20 个固定随机种子，246 场战斗，全部点亮三灯塔。模拟选择同伴和战斗行为、跳过步行，并访问不同生态区。无法代替对地图引导或新手理解的真人评估。
- `tests/collection.gd`：后期 99 级同伴的收藏流程，107/107 野外招募成功，142 次契约符尝试。实际调用安抚与捕捉，验证全队＋储备共 108 只、永久图鉴、本地完成称号及保存。该用例测试极端等级下收藏不被伤害溢出阻断，不代表初始难度。
- 六个 WAV 音轨均为单声道 16 位 PCM、非静音、内容不同，无削波。时长 6.4–14.72 秒；循环配乐仍需听感和重复疲劳评估。
- Godot 源码包解压到独立路径后重新导入和运行，不依赖原项目 `.godot` 缓存。

## 图形检查

实际运行 `tests/visual.gd`，捕获标题、探索、战斗、设置、分页图鉴、宠物详情、群岛地图、主角档案。标题的右边界裁切已修复。

窗口设为 1024×768、1280×720、1920×1080。采用 `canvas_items` + `keep`，可见参考画布分别为 1024×640、1152×720、1728×1080，其余部分留边，保持布局与命中位置一致。截图是游戏画布，不包含操作系统窗口装饰或留边。

音频在退出前停止并让播放器完成一轮处理后再释放，解决快速退出时的音频资源警告。当前测试日志无脚本错误或资源泄漏。Xvfb 提示不支持切换垂直同步，仅为虚拟显示驱动限制。

## 新档端到端实际输入

`tests/journey.gd` 从标题开始新档，按实际 WASD/T/E/R 和 GUI 鼠标点击完成九区游历、108 图鉴、三灯塔与三个生态委托。没有直接设置生命、等级、宠物、敌人、胜场或目标状态；仅固定随机种子并设置 10 倍模拟时间。

种子 `20261018` 验证两次：均为 155 场遭遇，663–667 次战斗操作、779–792 步、694–698 次 GUI 点击，零全队倒下，实际耗时约 89–90 秒。实际输入事件的帧时机使细节数字有小幅变化，终态目标一致。开局使用默认 1 级苔芽兽。此结果证明正常输入可完成流程，不证明手感、选择多样性或商业吸引力。

运行 `bash scripts/test.sh --journey` 会使用新的临时数据目录，不影响玩家存档。慢速机器允许至多 200 秒；测试内部有 180 秒保护。该测试不计入 741 项快速检查。
