# 潮汐灵约 / Tidebound

Godot 4.6 原创 2D 怪物收集单机游戏的v0.2.0 短篇原型。程序绘制像素风角色与地图，无第三方美术依赖。**当前是玩法原型，不是可直接售卖的 Steam 成品。** 暂定名称尚未进行商标或商店重名检索。

## 开始游玩

用 Godot 4.6.3 打开 `project.godot`，按 F6/F5 运行，或：

```bash
./scripts/run.sh
```

云机器无图形桌面时可以运行无窗口验证；实际游玩请在具备图形桌面的机器打开项目。已打包 Noto Sans CJK 中文字体与 OFL 许可。

- WASD / 方向键移动；草丛中随机遭遇灵兽。
- 点击战斗按钮：攻击、属性技、防御回血、契约捕捉、撤离。
- 森克潮、潮克焰、焰克森；对手生命越低，捕捉成功率越高。
- 队伍最多 6 只，切换出战灵兽会消耗一回合。
- 西侧帐篷旁按 E 或点击休息，恢复全队并补给契约符。
- 战斗胜利或捕捉获得潮晶，3 枚潮晶解锁东北遗迹守卫；点亮灯塔后启航下一座岛，共三章并包含结局。
- T 摇潮铃：低潮开启浅滩并增强焰属性技，高潮增强潮属性技并改变遭遇种类。
- 普通攻击或防御恢复潮息，共鸣技消耗 2 点；每场有 3 份药草。
- 队伍满六只时，新同伴进入营地储备；在营地可交换队伍。图鉴会永久记录已结识的九种灵兽。
- Esc 打开菜单；支持音量、全屏和键盘按钮焦点导航。手柄方向键/摇杆移动，Start 菜单，X 摇铃，Y 休息（仍需实机验证）。
- 战斗奖励和营地休息自动存档，也可手动保存；下次打开自动读档。
- 存档位于 Godot `user://tidebound_v2.json`，删除此文件可重开。云环境使用 `/workspace/.tidebound/data` 下的应用数据目录。

## 验证

```bash
./scripts/run.sh --headless --editor --quit
./scripts/test.sh
./scripts/run.sh --headless --quit-after 120
```

测试使用隔离的临时用户目录，不覆盖玩家存档。33 项集成检查涵盖克制、地图边界、攻击反击、胜利奖励、升级、遗迹解锁、捕捉、切换、失败恢复及保存读取。无窗口检查不等于图形界面或手感验收。

## Godot 源码交付

交付仅包含 Godot 项目源码 ZIP，不需要 Visual Studio、C++、Windows 或 Linux 平台源码。解压后在 Godot 项目管理器点击“导入”，选择 `project.godot`，等待字体导入完成后按 F5。

版本源码包保存在 `build/releases/Tidebound-v版本号-Godot-Source.zip`。用 `python3 scripts/package.py 0.2.0` 重新生成（Python 仅用于打包，运行游戏不需要 Python）。

仓库保留可选的导出预设，运行项目本身不需要安装导出模板。

商业方向、内容规划与发行条件见 [制作与发行路线](docs/ROADMAP.md)。

## 里程碑下载

GitHub 开发分支保存版本提交，Godot 源码 ZIP 解压即可导入。`.godot` 导入缓存、用户存档和第三方引擎二进制不包含在源码包内。

源代码与原创资源目前未授予公共开源许可证；Godot 和 Noto 字体分别遵循随附第三方许可证。Steam 商店尚未提交，本版本仍需平台测试、平衡和真人试玩。
